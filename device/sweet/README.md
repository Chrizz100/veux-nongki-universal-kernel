# SWEET: Gerätereferenz

Redmi Note 10 Pro (`sweet`), Android 13, MIUI V14.0.9.0.TKFEUXM.

`reference/stock.config` ist die unveränderte, aus der bereitgestellten boot.img
extrahierte Konfiguration. Der SHA256-Pin steht in `lineages/sweet/source_lock.json`.
Die drei großen Original-Images bleiben außerhalb dieses Git-Pakets.

Gerätepatches sowie eine spätere AK3-/Boot-v2-Paketierung werden in diesem
Gerätebereich ergänzt, sobald die Kernelbasis und Integration geprüft sind.
R4 enthält weder solche Patches noch einen flashbaren Kernel.

VEUX-Referenzen unter `device/veux/` werden nicht verwendet oder ersetzt.
